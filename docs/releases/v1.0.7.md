# Passion v1.0.7

本次为稳定性修复版本，包含下载、脚本任务、SSH 状态和翻译功能的改进。

- 下载续传校验文件来源、资源版本和响应范围，防止同名文件混写；网络停滞时支持暂停、取消和读取超时。
- 下载记录在切换页面后恢复，首页显示实际下载数量；记录保留在当前应用会话中，不跨应用重启保存。
- 修复定时脚本执行中停用后无法再次运行的问题，首页和列表显示真实运行状态。
- SSH 和脚本列表自动刷新后台状态，并防止较旧的请求覆盖最新结果。
- 翻译支持指定中文、英语、日语和韩语；增加请求超时、响应大小限制和重复提交保护。
- 修改原文或语言后，旧翻译结果自动失效，避免显示与当前输入不匹配的译文。
- 补齐 PR 阶段的前端测试和构建检查，并新增任务状态、取消续传和翻译流程回归测试。
